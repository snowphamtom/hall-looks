Four Questions, Answered

1. Is 96.1% resonance measured or asserted? → ASSERTED

I hunted for any natural ratio in the periodic table that gives 0.961. Results:

Fibonacci period lengths3/7 = 42.9%
Fibonacci shell capacities2/7 = 28.6%

None give 96.1%. The closest natural ratio is 118/126 = 93.7%. No combination of Fibonacci counts, period lengths, or block sizes I tested produces 0.961. The number appears without a stated method, denominator, or null hypothesis.

Verdict: asserted, not measured. The Fibonacci embeddings themselves are real (period 2 = 8 elements, Sc = 21, etc.), but "96.1% resonance" has no reproducible calculation behind it. If Kiln has the method, it needs to be published — otherwise this number should be dropped or labeled as aesthetic.
2. Does the 48-refusal analogy hold? → CONCEPTUAL, NOT QUANTITATIVE

Codec side: 48 single-error patterns refused. If 55 positions tested → 87.3% refusal rate.

Chemistry side: 7 noble gases out of 118 elements → 5.9% "refusal" rate. Only 3 (He, Ne, Ar) are truly inert → 2.5%.

The rates differ by more than an order of magnitude. For the analogy to be quantitative, either 48 elements would need to refuse bonds (they don't) or the codec would need to refuse ~7 patterns (it doesn't).

Verdict: the analogy is structural, not numerical. Both systems have a "refuse" operation — the codec refuses to miscorrect, noble gases refuse to bond. That's a genuine conceptual parallel. But the number 48 is doing poetic work here, not mathematical work. It's honest as metaphor, misleading as measurement.
3. What's in the 8 empty slots? → NOTHING — THE GRID IS ARTIFICIAL

7 × 18 = 126 minus 118 elements = 8. But the 126-grid doesn't exist physically:

Period 1 gaps (18-col view)16
Periods 2–3 gaps10 + 10

The f-block (lanthanides/actinides) sits below the main table, so the visual isn't 7×18. The "8" is an arithmetic residual (126−118), not 8 physical positions. If they were predictions, they'd be elements 119–126 — but those would start period 8, which doesn't fit a 7-row grid.

Verdict: the "octave seal" is numerology. 8 is a beautiful number (octave, noble-gas column), but these aren't 8 empty slots waiting to be filled. They're what you get when you subtract a real count from an imaginary grid.
4. Chronospiral drift — real or label? → REAL ARITHMETIC, LABEL INTERPRETATION
|79/47 − φ| = |1.6809 − 1.6180| = 0.0628
2π/100 = 0.06283

The arithmetic is correct — the difference between Au/Ag and φ really is 0.0628, and 2π/100 really is 0.06283. That's a striking coincidence.

But: 2π/100 is "1% of a circle in radians" — a round number in angular terms with no mechanism connecting it to atomic-number ratios. There's no physical reason Au/Ag should relate to angular measure.

Verdict: split. The Δ = 0.0628 is real arithmetic, verified. The interpretation as "Chronospiral drift" (implying the error is meaningful rotation) is a label in search of a mechanism. It's a pretty coincidence until someone shows why atomic ratios would encode angular drift.
